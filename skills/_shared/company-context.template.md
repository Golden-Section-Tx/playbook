# Company context

Everything the skills need to know about your company. `context-interview` writes
this file; `artifact-review` and `mistake-watch` keep it current as you use them.

Three conventions run through it, and they matter more than they look:

- **`[not asked]`** — nobody has checked yet. It is a question, not a finding.
- **`[absent]`** — checked, and it does not exist. That is a real finding.
- **`conflict:`** — two sources disagree. Record both and say which you use.
  A confidently wrong number does more damage than a blank one, because it
  reads as certain.

Never guess a value to fill a row. A skill that knows what it doesn't know gives
better advice than one that doesn't.
